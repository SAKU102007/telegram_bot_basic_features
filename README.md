# Telegram Bot: Basic Features

Учебный проект, демонстрирующий основные возможности разработки Telegram-ботов с использованием библиотеки **aiogram**.

В проекте реализованы примеры обработки команд, отправки различных типов сообщений, создания клавиатур и работы с inline-кнопками.

> [!IMPORTANT]
> Проект разработан с использованием **Python 3.10** и библиотеки **aiogram 2.25.1**.
>
> **Python 3.13 и новее не поддерживаются**, так как `aiogram 2.25.1` несовместим с этими версиями Python.

---

## 📌 Возможности

Бот поддерживает следующие функции:

- обработка команд;
- отправка текстовых сообщений;
- отправка стикеров;
- отправка фотографий;
- отправка видео;
- отправка видеосообщений (video note);
- отправка группы медиафайлов;
- создание и удаление Reply Keyboard;
- создание Inline Keyboard;
- обработка нажатий на Inline-кнопки;
- генерация случайного числа;
- очистка истории сообщений чата.

# Требования

Перед запуском необходимо установить:

- Python **3.10**
- pip

Проверить можно командами:

```bash
python --version
pip --version
```

Ожидаемый результат:

```text
Python 3.10.x
```

Если у вас установлена версия Python **3.13** или новее, необходимо установить **Python 3.10**, поскольку библиотека **aiogram 2.25.1** не поддерживает более новые версии Python.

# Установка проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/SAKU102007/telegram_bot_basic_features.git
```

или скачать архив проекта с GitHub.

После этого перейти в папку проекта.

```bash
cd telegram_bot_basic_features
```

---

### 2. Создать виртуальное окружение (рекомендуется)

**Windows**

```bash
py -3.10 -m venv venv
venv\Scripts\activate
```

**Linux / macOS**

```bash
python3.10 -m venv venv
source venv/bin/activate
```

---

### 3. Установить зависимости

Все необходимые библиотеки перечислены в файле `pip_requirements.txt`.

Установить их можно командой

```bash
pip install -r pip_requirements.txt
```

# Настройка Telegram API

Перед запуском необходимо получить токен своего Telegram-бота.

## Шаг 1

Открыть Telegram и найти бота

**@BotFather**

Это официальный бот Telegram для создания других ботов.

---

## Шаг 2

Отправить команду

```
/newbot
```

---

## Шаг 3

Придумать имя будущего бота.

Например

```
My Test Bot
```

---

## Шаг 4

Придумать username.

Он обязательно должен заканчиваться на

```
bot
```

Например

```
my_test_example_bot
```

---

## Шаг 5

После успешного создания BotFather отправит сообщение примерно такого вида

```
Use this token to access the HTTP API:

123456789:AAHXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

Скопируйте этот токен.

---

# Создание файла .env

В корневой папке проекта создайте файл

```
.env
```

Добавьте в него строку

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

Например

```env
BOT_TOKEN=123456789:AAHXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

Никаких кавычек использовать не нужно.

---

# Запуск проекта

После выполнения всех предыдущих шагов запустите

```bash
python basic_bot.py
```

Если всё настроено правильно, бот начнет работать.

# Возможные ошибки

### ModuleNotFoundError

Не установлены зависимости.

Решение:

```bash
pip install -r pip_requirements.txt
```

---

### BOT_TOKEN is None

Не найден файл `.env` или неверно указано название переменной.

Проверьте, что файл называется именно

```
.env
```

и содержит

```env
BOT_TOKEN=ваш_токен
```

---

### Unauthorized

Указан неверный токен.

Создайте нового бота через **@BotFather** или скопируйте токен заново.

---

### Фотографии или видео не отправляются

Убедитесь, что файлы

- `messi.jpg`
- `messi.mp4`
- `messi_video_note.mp4`

находятся в одной директории с `basic_bot.py`.
